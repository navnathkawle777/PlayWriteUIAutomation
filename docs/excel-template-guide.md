# Excel Template Guide

## Required columns
- request_id
- username
- first_name
- last_name
- email
- groups
- roles
- action

## Multiple groups
Use comma-separated values.

Example:
Claims_Maker,Claims_Viewer

## Multiple roles
Use comma-separated values.

Example:
Maker,Viewer

## Password handling
Do not store permanent passwords in Excel.
Use temporary password with force reset.
