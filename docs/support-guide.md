# Support Guide

## Common issues
1. Login failure
2. Portal timeout
3. Selector changed
4. Group not found
5. Role not found
6. Duplicate user
7. Save confirmation not received

## Troubleshooting
- Check screenshot
- Open Playwright trace
- Review structured log
- Validate input row
- Confirm Newgen availability
- Confirm automation account permissions

## Escalation
Escalate to:
1. Automation owner
2. Newgen application owner
3. Security/IAM team
4. Infrastructure/network team
